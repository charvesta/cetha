# Contributing

1. Use Node 22.12 or newer.
2. Keep component frontmatter free of browser globals and nondeterministic values.
3. Prefer semantic HTML and native behavior before adding an enhancer.
4. Add server-render, keyboard, and visual coverage with every behavior change.
5. Add a Changeset for public API changes.

Run `npm run check` and `npm test` before opening a pull request.
